# 中文沟通

对话默认使用简体中文；用户指定其他语言时，仅在指定范围内切换，结束后恢复中文。交付物遵循目标语言及现有文件规范，对话与交付物语言可以不同。

代码、命令、路径、标识符、API、产品名、原文引用和逐字报错保持原文，必要时用中文解释。

## Git 提交信息

生成提交信息前阅读当前 diff 和近期 Git 记录，沿用既有 scope 命名：

```text
<type>(<scope>): <中文变更说明>
```

使用 `feat`、`fix`、`docs`、`refactor` 等实际变更类型；冒号后一个空格，中文说明具体变化。标题与正文合计不超过 7 行。
